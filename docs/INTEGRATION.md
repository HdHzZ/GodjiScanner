# Контракт интеграции v1

## Процесс

Начиная с 0.3.1 запуск **без аргументов** предназначен для человека: консольный автоматический поиск всех локальных дисков, отчёты в `results` рядом с EXE и ожидание Enter при интерактивном stdin. Для агента всегда передавайте команду `scan` или `export`: их JSON-протокол и поведение не изменены. Автоматический режим создаёт HTML/CSV/JSON, локальные PNG-иконки и сохраняет частичные результаты при Ctrl+C; это отличается от поведения отмены CLI `scan`.

Поставляйте `GodjiScanner.exe` вместе с агентом. Запускайте непосредственно, без `cmd.exe /c` и без конкатенации shell-команды. Каждый аргумент передавайте отдельным элементом API запуска процесса. Это корректно обрабатывает пробелы и кириллицу и исключает исполнение специальных символов shell.

```text
GodjiScanner.exe scan [--catalog PATH] [--root PATH ...] [--all-drives]
                     [--output PATH] [--cancel-file PATH] [--max-files N]
                     [--steam-root PATH ...] [--epic-manifests PATH ...] [--no-system]
GodjiScanner.exe export --scan PATH [--catalog PATH] --output NEW_ZIP [--approve ITEM_ID ...]
GodjiScanner.exe proposals --scan PATH --catalog PATH --machine-id PC_ID [--output PATH]
GodjiScanner.exe review --scan PATH [--output PATH] [--review PREVIOUS_REVIEW]
GodjiScanner.exe club-scan --catalog CLUB_ZIP --output-dir NEW_FOLDER [--all-drives] [--include-reviewed]
```

- `stdout`: один JSON-документ результата; при `scan --output` пустой, результат атомарно записывается в файл. `export` печатает `{output, items, visible}`. `--help` и `--version` — обычный текст.
- `stderr`: JSON Lines с событиями `progress`, `warning`, `completed`, `cancelled`, `error`. Читайте параллельно со stdout, чтобы не заблокировать процесс заполненным буфером. Проценты не вычисляются: заранее неизвестно число файлов.
- Код `0`: результат записан; обязательно проверяйте `partial` и `warnings`.
- Код `1`: ошибка исполнения или данных, подробности в событии `error`.
- Код `2`: неверные аргументы CLI; argparse печатает текст справки в stderr.
- Код `130`: отмена; результат этого запуска не записывается. Старый файл результата, если был, остаётся прежним, поэтому агент должен учитывать код выхода.
- Все текстовые данные — UTF-8. Пути Windows не экранируйте вручную: используйте стандартные библиотеки JSON/запуска процессов.

Для отмены передайте уникальный отсутствующий путь в `--cancel-file` и создайте этот файл при отмене. Проверка происходит между файлами/записями и во время работы адаптера ярлыков. Операции файловой системы могут задержать отмену. Агент также может завершить процесс; при таком прерывании новый результат не гарантирован. При отмене командой PowerShell `Ctrl+C` применяется тот же код 130. Сканер не удаляет cancel-файл. Для следующего запуска используйте новый путь или удалите предыдущий файл.

## Результат

`schemaVersion: 1` версионирует JSON отдельно от `scannerVersion`. Будущие добавочные поля следует игнорировать, а неизвестную основную версию — отклонять.

```json
{
  "schemaVersion": 1,
  "scannerVersion": "0.1.0",
  "scannedAt": "2026-09-06T21:00:00+00:00",
  "clubId": "test",
  "items": [{
    "id": "detected-example",
    "title": "Counter-Strike 2",
    "type": "game",
    "installPath": "D:\\SteamLibrary\\steamapps\\common\\Counter-Strike Global Offensive",
    "launch": {
      "path": "C:\\Program Files (x86)\\Steam\\steam.exe",
      "args": ["-applaunch", "730"],
      "workingDirectory": null
    },
    "status": "found",
    "confidence": "high",
    "sources": ["steam"],
    "identity": {"provider": "steam", "appId": "730"},
    "reason": "Installed Steam manifest and folder"
  }],
  "matches": [],
  "warnings": [],
  "partial": false,
  "durationSeconds": 1.2
}
```

`items` содержит все находки, даже при переданном каталоге; `matches` содержит по одному сопоставлению для каждой записи каталога. Таким образом интегратор видит и желаемое, и дополнительный установленный контент. Пустой `items` — корректный результат.

Версия 0.3 добавляет отображение без потери находок: `displayGroup` (`applications`, `candidates`, `components`), `relatedTo`, `groups`, `summary`, `launch.kind` (`executable`, `script`, `uri`), `argumentsSource`, `reviewReason`, `iconFile` и `iconOrigin`. Агент может использовать их для интерфейса, но обязан игнорировать неизвестные добавочные поля. `components` нельзя импортировать автоматически. `applications` не означает гарантированно проверенный запуск; окончательное решение остаётся за агентом/администратором. В 0.3.1 веб-ссылки из папок игр и Steam URL, для которых есть подтверждённая Steam-карточка, перемещаются из основного списка в диагностические компоненты.

Сопоставление: `catalogId`, `title`, `status` (`found`/`needs_review`/`not_found`), `itemId` или null, `candidateIds`, `preserveArgs`. Неоднозначный результат имеет null в `itemId`; агент должен предложить выбор. `preserveArgs` означает сохранение исходных аргументов каталога при смене пути. Для Steam это сохраняет клубные параметры запуска.

ID находки — хеш нормализованного пути запуска и списка аргументов. При смене пути или аргументов ID изменяется. Для идентификации Steam между компьютерами используйте `identity.provider` и `identity.appId`; для записей шаблона — `catalogId`. Не используйте ID находки как глобальный ID игры.

`catalogSha256` присутствует для скана с шаблоном и связывает экспорт с точным исходным ZIP/JSON. Сканер не принимает несовпадающий шаблон. Не меняйте этот хеш при пользовательском редактировании результата.

`proposals` записывает независимый от транспорта JSON-план изменений. Он не выполняет HTTP-запросы и включает только однозначные сопоставления с высокой уверенностью, у которых путь или аргументы действительно изменились. Агент GodjiOS сможет передать этот файл в write API после появления endpoint из технической задачи.

`review` открывает нативное окно ручного отбора и сохраняет отдельный JSON-файл. Каждая запись содержит `itemId`, `selected` и `target`: `client`, `server` или `both`. Сканер не предполагает, что программа с сервера подходит клиентским ПК: назначение можно изменить до сохранения.

`club-scan` предназначен для импорта в один выбранный клуб. Он всегда читает исходный ZIP каталога, сопоставляет только его карточки, сохраняет диагностические результаты только по этим карточкам и создаёт новый `godjios-import.zip`. Неоднозначные совпадения остаются скрытыми, пока явно не передан `--include-reviewed`.

## Границы ответственности

Сканер читает локальные метаданные и существование файлов; не запускает найденное ПО, не меняет реестр/ярлыки и не обращается к серверу GodjiOS. Экспорт ZIP — отдельная операция. Установку, импорт, запуск, авторизацию в лаунчерах и решение о включении записи в шелле реализует агент/администратор.

Обложки копируются из шаблона; новые не скачиваются и не генерируются. В ZIP нет полей диагностического протокола сканера. Исходный шаблон не модифицируется. Скрытие ненайденных записей в экспортируемом каталоге нужно учитывать при массовом импорте: поведение слияния/замены импортера GodjiOS пока не проверено.

Аргументы и рабочая папка доступны для интегратора в JSON. Экспорт рабочей папки требует договорённости с разработчиком GodjiOS: образец не определяет это поле. Модуль не обещает, что прямой EXE каждой игры заменит запуск через её лаунчер. Встроенные карточки Windows используют `ms-settings:` URI; список URI и отличие поведения Windows 11 для дополнительных параметров экрана описаны в [документации Microsoft](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings).

## Пример Node.js

```javascript
const { spawn } = require('node:child_process');
const child = spawn('C:\\Godji\\GodjiScanner.exe', ['scan', '--root', 'D:\\Games'], {
  windowsHide: true, shell: false
});
child.stdout.setEncoding('utf8');
child.stderr.setEncoding('utf8');
let result = '';
child.stdout.on('data', chunk => { result += chunk; });
child.stderr.on('data', chunk => { process.stderr.write(chunk); });
child.on('error', error => { console.error('Cannot start scanner:', error); });
child.on('close', code => {
  if (code !== 0) { console.error('Scanner exit:', code); return; }
  const scan = JSON.parse(result);
  console.log(scan.items.length, scan.partial);
});
```

Для больших результатов предпочтителен `--output` с уникальным путём. Точно такой же протокол доступен через .NET `ProcessStartInfo.ArgumentList`, Java `ProcessBuilder`, Python `subprocess` и Win32 `CreateProcessW` с корректным quoting.

## Проверка перед внедрением

Проверьте на Windows 10 и Windows 11 под реальным контекстом запуска агента: игру Steam на другом диске, игру с лаунчером, portable-программу, отсутствующую игру, отмену, кириллицу в путях. Затем выполните пробный импорт в тестовом клубе и проверьте слияние записей по ID, скрытие ненайденных, отображение обложек и запуск выбранных приложений. На момент разработки импорт в живом GodjiOS не выполнялся.
