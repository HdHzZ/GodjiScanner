# Каталоги клубов

Поместите сюда экспортированный из GodjiOS ZIP-каталог каждого клуба. Название файла может быть, например, `Бор.zip`.

Откройте `GodjiScanner.exe clubs`, выберите клуб и запустите сканирование. Исходные ZIP-файлы намеренно не добавляются в Git, потому что содержат данные конкретного клуба.
